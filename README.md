# パチスロ設定判別ツール - GitHub Pages 移行ガイド

このリポジトリは、**Google AI Studio Build** で作成された「パチスロ設定判別ツール」を、無料・高速で稼働する **GitHub Pages** へ完全移行・公開するための設定がすべて最適化されたコードベースです。

---

## 🚀 GitHub Pages 移行の特徴

1. **完全無料・無制限アクセス**: 
   - Google AI Studio（Cloud Run）環境と異なり、サーバーリクエスト毎の従量課金やアクセス集中による起動待機・費用は一切発生しません。
2. **高速キャッシュ（オフライン対応）**: 
   - すでに実装されている Service Worker（`sw.js`）は、移行後のサブディレクトリ環境（`https://username.github.io/repo/`）でも適切に全アセット（背景画像、キャラアイコン、スクリプト）をキャッシュするように、**完全に相対パスへと再構成済み**です。
3. **継続的デプロイ（GitHub Actions対応）**: 
   - 自動デプロイ設定ファイル（`.github/workflows/deploy.yml`）を同封しているため、GitHub にコードをプッシュするだけで、自動で最新版がビルドされてデプロイされます。

---

## 🛠️ GitHub Pages への設置手順 (簡単4ステップ)

### ステップ 1: コードをダウンロードする
1. Google AI Studio（この画面）の右上または設定メニューから、**「Export to GitHub」**または**「Export to ZIP」**をクリックし、コードの最新スナップショットをダウンロード、またはご自身の GitHub アカウントに連携してください。
   - ZIPでダウンロードした場合は、パソコン上で一度解凍しておきます。

### ステップ 2: 新規リポジトリを作成
1. ご自身の [GitHub](https://github.com/) ページにアクセスしてログインします。
2. 右上の「**+**」から **「New repository」**（新しいリポジトリ）を選択します。
3. リポジトリ設定画面で以下を入力します：
   - **Repository name**: `pachislot-tool` (お好みの名前)
   - **Public / Private**: 
     - 誰でもアクセスさせたい場合は **Public**。
     - 特定の人のみ閲覧・アクセスさせたい場合は、GitHub の **Private** 機能（有料アカウント等によるアクセス制限制限）を利用することも可能です。
4. その他のオプション（READMEの追加など）は**チェックを入れずに**、「**Create repository**」をクリックします。

### ステップ 3: コードのプッシュ（アップロード）
作成後の画面に表示されるコマンド、あるいはフォルダをご自身のローカル環境から Git でプッシュします。

```bash
# ローカルで解凍したディレクトリのルート（package.jsonがある場所）で実行する場合：
git init
git checkout -b main
git add .
git commit -m "feat: GitHub Pages への完全移行最適化"
git remote add origin https://github.com/あなたのユーザー名/リポジトリ名.git
git push -u origin main
```
*(Git コマンドが難しい場合は、GitHubのWeb画面上部にある「uploading an existing file」からフォルダ丸ごとブラウザでドラッグ＆ドロップしてコミットすることも可能です。)*

### ステップ 4: GitHub 側の配信切替（★最重要）
GitHub のリポジトリ画面から、自動ビルド・デプロイを行うための設定を行います。

1. 作成したリポジトリの **「Settings（設定）」** タブをクリックします。
2. 左メニューの **「Pages」** を選択します。
3. **Build and deployment** セクション内にある **「Source」** ドロップダウンメニューをクリックします。
4. **「Deploy from a branch」** から **「GitHub Actions」** に変更します。

これだけで設定は完了です！  
自動的に先ほど作成した `.github/workflows/deploy.yml` が裏で走り、約1〜2分以内に公開用URLが発行されます。

---

## 📱 公開完了後のアクセスURL
公開ページは以下の形式になります：
`https://あなたのユーザー名.github.io/リポジトリ名/`

携帯のホーム画面に「ショートカット/ホーム画面追加」を行っても、Cloud Run のような待機・コールドスタート時間を一切挟まず、爆速で常時開くことができるようになります。

## ⚙️ 完了している調整一覧
本コードベースでは、GitHub Pages（サブディレクトリ配信）で発生する一般的な不具合をすべて事前改修してあります：
* **`vite.config.ts` の `base: './'` 化**: すべてのスクリプトとアセット参照が相対パスにコンパイルされます。
* **`index.html` の絶対参照解除**: 絶対パス `/zz_image/...` や `/index.css` をすべて `./`（相対）に変換しました。
* **Service Worker 内 `URLS_TO_CACHE` の修正**: オフラインキャッシュのターゲットになるパスから先頭のスラッシュを取り除き、下層のパス名でも正常に画像がキャッシュされるようにしました。
* **モデル連携/キャラクター画像配列のパス修正**: `/constants/monkeyTurnVConstants.ts` 等の各画像一覧配列から絶対パスを完全に廃止しました。
